## Components

### Buttons
**`button-primary`** — The primary call-to-action across the site, used for “Add to Cart,” “Shop Now,” and checkout flows. Rendered in the brand’s signature blue {colors.primary} with white text and a soft 8px corner radius ({rounded.sm}). On hover, the background shifts to {colors.primary-active} (#0056a7) with no border change. The disabled state uses {colors.primary-disabled} (#d0d5d2) with muted text, signaling the button is non-interactive. Height is fixed at 48px with 14px vertical and 28px horizontal padding.

**`button-secondary`** — An outlined variant for secondary actions like “Learn More” or “View Details.” Uses a white background ({colors.canvas}) with {colors.primary} text and a 1px solid border in {colors.primary}. On hover, the background fills with {colors.surface-soft} (#eeeeee) and the text shifts to {colors.primary-active}. Same 48px height and 8px corner radius as the primary button.

**`button-tertiary-text`** — A text-only button for inline actions such as “Clear Filters” or “Cancel.” No background, no border — just {colors.primary} text in the button-md type style. On hover, the text color shifts to {colors.primary-active} with no underline.

### Text Inputs
**`text-input`** — Standard form input for search, email signup, and address fields. Uses a white background ({colors.canvas}) with {colors.ink} text, 8px corner radius ({rounded.sm}), and 12px/16px padding. On focus, the input gains a 2px blue ring ({colors.primary} at 25% opacity) and a 1px solid border in {colors.primary}. Height is fixed at 48px to match button heights.

### Navigation
**`nav-bar`** — The top-level site navigation bar, fixed at 72px height and filled with {colors.primary} blue. Navigation links use {colors.on-primary} white text in the nav-link type style (15px, weight 500). The active link is indicated by a 2px white bottom border. The bar contains the brand logo (left), category links (center), and utility icons (search, cart, account — right).

**`nav-link`** — Individual navigation link within the nav-bar. White text, 15px Rubik weight 500, with 8px/16px padding. On hover, the link gains a subtle white underline.

### Product Cards
**`product-card`** — The core product display unit on collection and search pages. A white card ({colors.surface-card}) with 12px padding and a 12px corner radius ({rounded.md}). Contains the product image (1:1 aspect ratio, 8px corner radius), title (title-sm type), price (body-md type), and the Cuddle Scale rating (filled/empty dots). On hover, the card lifts with a subtle box-shadow and gains a 2px blue border ({colors.primary}).

**`cuddle-scale-dot-filled`** — A 12px filled circle in {colors.primary} blue, used to indicate softness rating on a 1-to-5 scale. The dot uses a full border radius ({rounded.full}) to create a perfect circle.

**`cuddle-scale-dot-empty`** — A 12px empty circle in {colors.hairline} (#d8d8d8), used as the unfilled portion of the Cuddle Scale. Same full border radius as the filled dot.

### Badges
**`badge-new`** — A small green badge ({colors.badge-new} #00d084) with white uppercase text in 11px weight 700. Used to flag newly arrived products. 4px corner radius ({rounded.xs}) and 2px/8px padding.

**`badge-sale`** — A small red badge ({colors.badge-sale} #cd2653) with white uppercase text. Used to flag discounted products. Same dimensions as the new badge.

### Star Rating
**`star-rating`** — A 16px star icon set in {colors.star-rating} (#f0b849) for customer review ratings. Displayed inline with product cards and review sections. The star icon uses a filled/empty pattern similar to the Cuddle Scale.

### Footer
**`footer`** — The site footer, a deep navy background ({colors.footer-bg} #212121) with white text. Contains link columns (About, Customer Service, Policies), social icons, and a copyright line. Links use {colors.footer-text} white and shift to {colors.teal} (#62a9aa) on hover. Padding is 48px vertical and 64px horizontal.

### Hero Section
**`hero-section`** — The homepage hero banner, using a soft gray background ({colors.surface-soft} #eeeeee) with 64px vertical padding. The hero title uses display-xl type (32px, weight 700) in {colors.ink}, and the subtitle uses body-md type (16px) in {colors.muted}. The hero typically features a large product image and a primary CTA button.

### Category Strip
**`category-strip`** — A horizontal scrollable strip of category tabs (e.g., “Bears,” “Bunnies,” “Dogs,” “Cats”) below the nav-bar. Tabs are styled as text links in {colors.muted} with 8px/16px padding. The active tab uses {colors.primary} text with a 2px blue bottom border.

## Responsive Behavior

| Name | Width | Key Changes |
|---|---|---|
| Mobile | < 744px | Nav-bar collapses to hamburger menu; product cards go to single-column grid (1 col); hero section reduces padding to 32px; category strip becomes horizontally scrollable with no active underline; footer stacks links vertically; Cuddle Scale dots reduce to 10px. |
| Tablet | 744–1128px | Nav-bar shows top-level categories as text links; product cards display in 2-column grid; hero section uses 48px padding; category strip shows 4-5 visible tabs with horizontal scroll; footer uses 2-column link layout. |
| Desktop | 1128–1440px | Full nav-bar with all categories visible; product cards in 3-column grid; hero section at full 64px padding; category strip shows all tabs without scroll; footer uses 4-column link layout. |
| Wide | > 1440px | Max-width container at 1440px with auto margins; product cards in 4-column grid; hero section scales up to 80px padding; all other layouts scale proportionally. |

### Touch Targets
- All buttons and interactive elements maintain a minimum 44px height (buttons are 48px, text inputs are 48px, nav links have 44px+ tap areas).
- Cuddle Scale dots are 12px with 8px gaps — on mobile, dots increase to 14px for easier tapping.
- Category strip tabs have 44px minimum tap height.
- Search bar is 48px tall with 24px horizontal padding for easy tapping.

### Collapsing Strategy
- Nav-bar collapses to a hamburger icon on mobile (< 744px), revealing a full-screen overlay menu with category links, search, and account options.
- Product card grid collapses from 4 columns (wide) to 3 (desktop) to 2 (tablet) to 1 (mobile).
- Category strip collapses from a full row of tabs to a horizontally scrollable strip on tablet and mobile.
- Footer collapses from 4 columns (desktop) to 2 columns (tablet) to a single vertical stack (mobile).
- Hero section collapses from a side-by-side layout (image + text) to a stacked layout (text above image) on mobile.
