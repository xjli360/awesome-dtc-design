## Components

### Buttons
**`button-primary`** — The primary call-to-action, rendered in the brand's coral-red (#ed4c5c) with white text. Used for "Subscribe Now", "Add to Cart", and "Join Waitlist" actions. On hover/active, shifts to a deeper red (#c8102e). Disabled state uses a soft pink (#f78da7) to indicate non-interactivity. All primary buttons use 8px corner rounding ({rounded.sm}) and 44px height for comfortable touch targets.

**`button-secondary`** — An outlined or ghost-style button on white canvas with ink (#1d0e45) text. Used for "Learn More", "View Details", and secondary checkout actions. Active state fills with the soft surface (#f9f9f9). Maintains the same 44px height and 8px rounding as the primary for visual consistency.

**`button-accent-purple`** — A secondary accent button using the brand's amethyst purple (#9243e2). Appears on tier-selection pages and promotional banners where the coral would compete with other coral elements. Same sizing and rounding as button-primary.

**`button-pill-primary`** — A compact, fully rounded pill variant of the primary button. Used for inline badges, filter tags, and "Shop Now" links within card components. Uses smaller button-sm typography and 8px vertical padding for a tighter footprint.

**`button-pill-accent`** — A gold (#f0b849) pill button used for "Exclusive" or "Limited Edition" callouts. The gold against dark backgrounds creates a premium, treasure-like feel. Text remains ink (#1d0e45) for contrast.

### Cards
**`product-card`** — The standard product display card for book boxes and exclusive editions. White background with 12px rounding ({rounded.md}), 16px padding, and body-sm typography for descriptions. The product image sits at the top with 8px rounding ({rounded.sm}). Price is always displayed in coral-red button-md weight to draw the eye.

**`product-card-badge`** — A pill-shaped badge overlaid on product images or attached to card headers. Four variants exist: default coral for "Best Seller", red (#dc3232) for "Sold Out", gold (#f0b849) for "Exclusive", and purple (#9243e2) for "New". All use uppercase 11px bold type with 0.5px letter spacing and 4px vertical padding.

**`subscription-tier-card`** — Larger cards used on the subscription comparison page. 16px rounding ({rounded.lg}), 24px padding, and body-md typography for feature lists. The featured tier (e.g., "Book Only + Goodies") gets a 2px gold border to distinguish it from standard tiers.

### Navigation
**`nav-bar`** — A fixed top navigation bar on the deep violet ink (#1d0e45) background. 64px tall with white/off-white nav links. Active or hovered links shift to coral (#ed4c5c). The bar contains the brand logo, main navigation links (Subscriptions, Shop, About, etc.), a search icon, and a cart icon.

**`nav-link`** — Individual navigation items with 8px horizontal padding. Uses 15px semibold system font. Active state uses coral text color; inactive uses off-white (#fffcf8).

### Forms
**`text-input`** — Standard text input for search, email signup, and checkout forms. White background with a hairline (#43454b) border, 8px rounding, and 44px height. On focus, the border switches to coral (#ed4c5c). Error state uses the error red (#cd2653) border.

**`search-bar`** — A fully rounded pill-shaped search input used in the nav bar and on search pages. 44px height with 20px horizontal padding. Focus state mirrors text-input with a coral border.

### Footer
**`footer`** — A full-width footer on the deep violet ink background with off-white text. Links use the light purple (#c188fb) for a magical, link-accessible accent. Social media icons are 36px circles with full rounding. The footer contains columns for customer service, subscription info, social links, and a newsletter signup.

**`footer-link`** — Footer navigation links in light purple (#c188fb) with standard link typography. Hover state shifts to coral (#ed4c5c).

### Other Components
**`hero-section`** — Full-width hero banners on the ink background with display-xl typography. Used for seasonal promotions, new subscription announcements, and featured collections. An accent variant uses the purple (#9243e2) background for visual variety across the homepage.

**`star-rating`** — Gold (#ffce31) star icons at 16px for product reviews and ratings. Displayed inline with product cards and subscription tier descriptions.

**`countdown-timer`** — A compact timer component for limited-edition drops and flash sales. Soft gray background (#f9f9f9) with coral text, 8px rounding, and 8px padding. Displays days, hours, minutes, and seconds in button-md weight.

## Responsive Behavior

| Name | Width | Key Changes |
|---|---|---|
| Mobile | < 744px | Single-column layout; nav bar collapses to hamburger menu; product cards stack vertically; hero sections reduce padding to 32px; subscription tier cards stack; search bar moves to full-width below nav |
| Tablet | 744–1128px | Two-column product grid; nav links remain visible but condensed; hero sections use 48px padding; subscription tier cards display in 2-column grid |
| Desktop | 1128–1440px | Three-column product grid; full nav bar with all links; hero sections use 64px padding; subscription tier cards in 3-column grid; search bar in nav |
| Wide | > 1440px | Max-width container at 1440px; content centered; product grid expands to 4 columns for large catalogs; hero sections remain full-bleed |

### Touch Targets
- All buttons and interactive elements maintain minimum 44px height for touch accessibility
- Nav links have 8px padding on each side, ensuring 31px+ tap targets
- Product cards have 16px padding, making entire card tappable
- Search bar and text inputs are 44px tall
- Social icons are 36px circles with 44px tap area via padding

### Collapsing Strategy
- On mobile, the top nav collapses to a hamburger menu with a slide-out drawer
- Product card badges reduce in size (8px vertical padding becomes 4px)
- Hero section text reduces from display-xl to display-md on mobile
- Subscription tier comparison collapses from side-by-side to stacked
- Footer columns collapse from 4-column to 2-column on tablet, single-column on mobile
- Star ratings hide text labels on mobile, showing only stars
