## Components

### Buttons
**`button-primary`** — The primary call-to-action, rendered in a high-contrast yellow (`{colors.accent-yellow}`) against the dark canvas. Used for "Add to Cart" and "Buy Now" actions. On hover, the yellow deepens to `#e6b800`; disabled state drops to a muted amber with gray text. **`button-secondary`** — A subdued alternative for less critical actions like "View Details" or "Wishlist." Uses the surface-soft background (`{colors.surface-soft}`) with body text, no border. **`button-tertiary`** — A text-only link styled as a button, used for "Learn More" or "See All" in category headers. Uses the link blue (`{colors.link}`) with no background. **`button-add-to-cart`** — The primary purchase action, taller (44px) than the standard button for better touch targeting. Same yellow background as `button-primary` but with increased padding for visual weight.

### Badges
**`badge-preorder`** — A bright yellow (`{colors.badge-preorder}`) uppercase label signaling upcoming releases. Applied as an absolute-positioned overlay on product card images. **`badge-sale`** — A red (`{colors.badge-sale}`) uppercase label for discounted items. Uses white text for maximum contrast against the dark card background. **`badge-region`** — A small, muted label indicating the game's region (e.g., "US", "JP", "ASIA"). Uses the surface-soft background with muted text, positioned below the product title.

### Navigation
**`nav-bar`** — A fixed 48px horizontal strip at the top of the page, using the primary dark background (`{colors.primary}`) with a subtle bottom border. Category links (PlayStation, Nintendo, PC, etc.) are spaced at 16px intervals. **`nav-link-default`** — Standard navigation link in body gray (`{colors.body}`). **`nav-link-active`** — Active or hovered navigation link in accent yellow (`{colors.accent-yellow}`), providing clear wayfinding. **`nav-link-hover`** — On hover, links transition to white (`{colors.on-primary}`) for a bright, readable state.

### Product Cards
**`product-card`** — The core content unit, a compact box containing a 1:1 product thumbnail, title, price, and optional badges. Uses the surface-card background (`{colors.surface-card}`) with subtle rounded corners (`{rounded.sm}`). Cards are arranged in a dense grid with minimal gap (`{spacing.sm}`). **`product-card-image`** — Square aspect ratio thumbnail with rounded corners. **`product-card-title`** — 14px bold title in white, positioned below the image. **`product-card-price`** — 16px bold price in white, the most prominent text element on the card. **`product-card-badge`** — Absolute-positioned overlay at the top-left of the card image for sale/preorder labels.

### Forms & Inputs
**`text-input`** — Standard text field for search and form entries. Uses the surface-soft background with a subtle border (`{colors.hairline}`). On focus, the border switches to accent yellow for clear active state indication. **`search-bar`** — A full-width input field with a magnifying glass icon, styled identically to `text-input` but with a search-specific role. **`filter-dropdown`** and **`sort-select`** — Compact dropdown controls for filtering and sorting product listings. Both use the surface-soft background with hairline border and body text. **`quantity-selector`** — A small numeric input for cart quantity adjustments, styled to match other form elements.

### Footer
**`footer`** — A dense, text-heavy footer spanning the full page width. Organized into columns by category (Help, My Account, Payment Methods, etc.), each with a white heading (`{colors.on-primary}`) and muted body links. **`footer-link`** — Standard footer link in muted gray, with hover state transitioning to white. **`footer-heading`** — 12px bold uppercase heading for each footer column.

### Navigation Aids
**`breadcrumb`** — A compact breadcrumb trail showing the current page path (e.g., "Home > PlayStation > PS5 Games"). Uses muted text for non-active segments and link blue for clickable ancestors. **`pagination`** — Page number navigation at the bottom of product listings. The active page is highlighted with a yellow background (`{colors.accent-yellow}`) and dark text; inactive pages are plain text. **`category-filter`** — Pill-shaped filter chips for quick category selection (e.g., "All", "Pre-order", "Sale"). Active chips use the yellow accent; inactive chips use the surface-soft background.

### Cart & Checkout
**`cart-item`** — A row in the shopping cart, showing product thumbnail, title, quantity selector, and price. Each item is separated by a hairline border. **`cart-total`** — The order total summary at the bottom of the cart, using the surface-soft background for visual separation. **`checkout-button`** — A full-width, 48px-tall button for proceeding to checkout. Uses the same yellow accent as `button-primary` but with increased height and full-width layout for prominence.

## Responsive Behavior

| Name | Width | Key Changes |
|---|---|---|
| Mobile | < 744px | Single-column product grid (1-2 columns), stacked navigation (hamburger menu), reduced padding, smaller card sizes, footer collapses to single column |
| Tablet | 744–1128px | Two-column product grid, horizontal nav bar visible, filter dropdowns remain, footer splits into 2-3 columns |
| Desktop | 1128–1440px | Three-to-four-column product grid, full horizontal nav, side filter panel optional, footer in 4-5 columns |
| Wide | > 1440px | Four-to-five-column product grid, max-width container (~1440px), additional whitespace on sides, full footer layout |

### Touch Targets
- All buttons and interactive elements maintain a minimum 40px height for touch accessibility
- Product card tap targets are the full card area (not just the title or price)
- Filter chips and pagination buttons are 32px+ in height
- Cart quantity selector uses 36px height for comfortable tapping
- Search bar and text inputs are 40px tall

### Collapsing Strategy
- On mobile (< 744px), the horizontal nav bar collapses into a hamburger menu with a slide-out drawer
- Category filter chips collapse into a single "Filter" dropdown button
- Product grid reduces from 4-5 columns to 1-2 columns
- Footer columns stack vertically into a single column
- Breadcrumb trail truncates to show only the last 2-3 levels
- Sort and filter controls collapse into a single toolbar row with icons
