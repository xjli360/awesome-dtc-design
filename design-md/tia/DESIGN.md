## Components

### Buttons
**`button-primary`** — The primary call-to-action, rendered in the brand’s signature fuchsia {colors.primary} with white text and a pill shape ({rounded.full}). Used for key actions like “Book an Appointment” or “Join Tia”. On hover, shifts to a deeper magenta {colors.primary-active}. **`button-secondary`** — A ghost-style button on the cream canvas {colors.canvas} with a subtle border {colors.hairline}. Used for secondary actions like “Learn More” or “View Providers”. On active state, the border thickens and darkens to {colors.ink}.

**`button-accent-coral`** — A coral variant {colors.accent-coral} for urgent or high-empathy CTAs (e.g., “Get Care Now”). Same pill shape and padding as primary, but the coral signals warmth and immediacy.

**`button-accent-mint`** — A mint variant {colors.accent-mint} for wellness-oriented actions (e.g., “Explore Mental Health”). Uses dark text {colors.ink} for contrast against the light green.

**`button-accent-wine`** — A deep wine variant {colors.accent-wine} for premium or membership-related CTAs (e.g., “Become a Member”). White text, same pill shape.

**`button-tertiary-text`** — A text-only link styled as a button, using {colors.primary} with an underline. Used for inline actions like “Sign In” or “View All Services”.

**`button-pill-small`** — A compact pill button for filters, tags, or mobile CTAs. Uses {typography.button-sm} and tighter padding.

## Responsive Behavior

| Name | Width | Key Changes |
|---|---|---|
| Mobile | < 744px | Single-column layout; nav collapses to hamburger; hero heading reduces to 32px; cards stack vertically; buttons become full-width; padding reduces to {spacing.base} |
| Tablet | 744–1024px | Two-column card grids; nav links visible but condensed; hero heading at 36px; side-by-side hero layout |
| Desktop | 1024–1440px | Three-column card grids; full nav bar; hero heading at 42px; multi-column footer |
| Wide | > 1440px | Max-width container (1200px) centered; extra whitespace on sides; hero may include background imagery |

### Touch Targets
- All interactive elements (buttons, links, inputs) have a minimum height of 44px and minimum width of 44px per WCAG 2.1 guidelines.
- Icon buttons and avatar links are at least 48px in diameter.
- Form inputs are 48px tall for comfortable tapping.
- Nav links have 16px padding on each side for a generous tap area.

### Collapsing Strategy
- On mobile, the top navigation collapses into a hamburger menu with a slide-out drawer.
- Multi-column card grids collapse to single-column stacks.
- The hero section’s side-by-side layout (text + image) collapses to a stacked layout with the image below the text.
- The footer’s multi-column link layout collapses to a single column with accordion-style expandable sections.
- Service category badges in a horizontal strip collapse to a scrollable horizontal row with overflow hidden.
