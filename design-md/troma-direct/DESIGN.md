## Components

### Buttons
**`button-primary`** — The standard WooCommerce blue (#007cba) button used for primary actions across the site. Flat, no rounded corners, with white text. On hover, shifts to a slightly darker blue (#006ba1). Disabled state uses the muted gray (#444444). Used for "Add to Cart", "Search", and form submissions.
**`button-secondary`** — An outlined variant using the canvas background (#eeeeee) with dark ink (#2f2f2f) text. Same flat styling, no rounded corners. Used for secondary actions like "View Cart" or "Continue Shopping".
**`add-to-cart`** — A compact version of the primary button, 40px tall with smaller padding. Uses the same WooCommerce blue (#007cba) and flat styling. Active state darkens to #006ba1. This is the most frequently used button on the site, appearing on every product card and product page.
**`checkout-button`** — A green (#4ab866) button reserved for the checkout flow, signaling a positive action. Same flat styling, no rounded corners. Active state darkens to #3a9e52. This is the only button that deviates from the WooCommerce blue, creating a visual distinction between "add to cart" and "complete purchase".

### Navigation
**`nav-bar`** — A horizontal strip at the top of the page using the canvas background (#eeeeee) with dark ink (#2f2f2f) text. 48px tall, no borders or shadows. Links are spaced with 16px horizontal padding. Active category links turn to the link blue (#003388).
**`nav-link`** — Inline navigation links using the system font at 14px weight 600. Default color is ink (#2f2f2f), active state is link blue (#003388). No underline or hover effects beyond color change.
**`breadcrumb`** — A simple text-based breadcrumb trail using caption-size type (13px). Current page is ink (#2f2f2f), links are link blue (#003388), separators are muted (#43454b). No icons or special styling.

### Cards
**`product-card`** — A white (#ffffff) card on the canvas (#eeeeee) background with no rounded corners, no shadows, and no borders. Contains the product image, title, price, and an "Add to Cart" button. The card has 16px padding. The only visual separation comes from the white card against the light gray canvas.
**`product-card-badge`** — A small pink (#cd2653) badge with white text, 12px bold, no rounded corners. Used for "Sale" or "New" indicators. A sold-out variant uses muted gray (#43454b) instead.
**`product-card-price`** — The current price is shown in 16px bold (#2f2f2f). If on sale, the sale price appears in pink (#cd2653) with the regular price shown as line-through in muted (#43454b) caption-size text.

### Forms
**`text-input`** — A standard text input with white background (#ffffff), dark text (#2f2f2f), and no rounded corners. 44px tall with 10px vertical padding. On focus, gets a 1px WooCommerce blue (#007cba) box-shadow. Error state uses the primary red (#cc1818) box-shadow.
**`search-input`** — A compact text input (36px tall) on the canvas background (#eeeeee) with dark text (#2f2f2f). No rounded corners. Paired with a WooCommerce blue (#007cba) search submit button of the same height.
**`select`** — A standard select dropdown with white background, dark text, no rounded corners. 44px tall. Used for sorting and filtering options.
**`quantity-input`** — A compact numeric input (40px tall) with white background. Paired with quantity adjustment buttons on the canvas background. No rounded corners.

### Footer
**`footer`** — A dense footer section on the canvas background (#eeeeee) with muted text (#43454b). Contains columns of category links in link blue (#003388), a newsletter signup form, and copyright information. 32px vertical padding. No borders or separators between sections.

### Alerts
**`alert-success`** — A green (#4ab866) alert bar with white text, no rounded corners. Used for success messages like "Item added to cart."
**`alert-error`** — A red (#cc1818) alert bar with white text. Used for error messages like "Please enter a valid coupon code."
**`alert-info`** — A bright blue (#2874fc) alert bar with white text. Used for informational messages.

## Responsive Behavior

| Name | Width | Key Changes |
|---|---|---|
| Mobile | < 768px | Navigation collapses to hamburger menu. Product cards stack in single column. Footer links stack vertically. Search form moves below navigation. |
| Tablet | 768–1024px | Navigation remains horizontal but with reduced padding. Product cards display in 2-column grid. Footer links in 2 columns. |
| Desktop | 1024–1440px | Full horizontal navigation. Product cards in 3-4 column grid. Footer links in 4 columns. Sidebar appears on product archive pages. |
| Wide | > 1440px | Max-width container (1200px) centered. Product cards in 4-5 column grid. Additional whitespace on sides. |

### Touch Targets
- All buttons and interactive elements are at least 44px tall (meeting WCAG minimum).
- Navigation links have 48px touch target height.
- Product card "Add to Cart" buttons are 40px tall.
- Quantity adjustment buttons are 40px × 40px.
- Search submit button is 36px × 36px (below recommended minimum but matches input height).

### Collapsing Strategy
- On mobile (< 768px), the main navigation collapses into a hamburger menu with a vertical dropdown.
- Product archive sidebar (filters, categories) collapses below the main content on mobile.
- Footer link columns collapse from 4 columns to 1 column on mobile.
- Product image gallery switches from grid to single-image swipe on mobile.
- Search form moves from inline in the header to a full-width bar below the navigation on mobile.
